# Rill interface system

## Visual thesis

Rill is a live procurement instrument, not a financial dashboard. Its split composition pairs a calm written mandate with a spatial payment-routing canvas. The canvas grid exists only to establish coordinates for agent-to-resource movement.

## Tokens

- Base: mineral paper `#EEF4F0`, ink `#101411`
- Protocol field: estuary teal `#00635F`, deep channel `#004B48`
- Active movement: warm signal `#FFB06A`
- Failure: coral `#ED5F59`
- Typography: Archivo Variable for product language; IBM Plex Mono for IDs, states, amounts, and receipts
- Geometry: square edges; circles are reserved for currency/state and the central router
- Motion: 320/24 spring character, 160–420 ms direct feedback, 1120 ms narrative stage pacing

## Resource application

- UI Skills: balanced headings, tabular figures, 44 px minimum controls, press feedback
- Design System Checklist: primitive/semantic tokens, device-specific grids, shared motion values
- Vibe Prompts: live collaboration canvas and agent-run trace, rewritten as procurement rather than a stock dashboard
- Interfaces by Rauno: labelled form controls, Enter submission, focus visibility, real disabled states
- COSS UI: semantic field, progress, segmented state, and receipt anatomy
- ReUI: dense operator-console hierarchy without importing its dashboard chrome
- Component Gallery: compared production anatomy and state behavior before composing controls
- Design Systems One: foundations-first token documentation and accessibility checks
- Utopia: fluid `clamp()` scales for type and space
- Open Props: systematic token naming and reusable easing conventions
- Kinetics: critically damped spring feedback and interruptible state motion
- Animated Buttons: one restrained arrow-push interaction for the primary action
- Motion Primitives: coordinated presence/exit behavior for the final receipt
- Icon Creator: consistent Lucide geometry and restraint; the brand remains a wordmark rather than a fabricated icon
- Ibelick Backgrounds: a low-contrast coordinate grid used only inside the routing field
