# Rill submission kit

## One-line pitch

Rill lets autonomous agents buy the smallest policy-safe set of machine resources, block duplicate work, and return an auditable decision receipt.

## 55-second demo script

1. **0–6s — problem:** “Agents can discover APIs, but they still need a safe way to decide what they are allowed to buy.”
2. **6–13s — mandate:** Show the BTC volatility job, 5.00 USDC budget, verified-provider policy, and simulation label.
3. **13–28s — run:** Press **Run procurement**. Narrate discovery, quote comparison, and the three amber authorizations.
4. **28–38s — evidence:** Point out the aqua packets returning from Binance market context, news, compute, and proof services.
5. **38–48s — receipt:** Show 0.68 USDC authorized under policy 2.0 and copy the deterministic receipt.
6. **48–55s — proof:** Briefly show `npm run demo`, `npm run demo:review`, and `npm run demo:block`. Close with: “Rill is the policy and receipt layer for machine payments on Binance Agent OS.”

## Recording checklist

- Use a laptop browser at 1440×900 or 1920×1080 and hide unrelated tabs or notifications.
- Start from the `Ready` state and keep the cursor still until the call to action.
- Record one uninterrupted run through the complete receipt.
- Add captions; do not use copyrighted music unless licensed.
- Show the GitHub repository and passing terminal proof for 4–6 seconds.
- Keep the simulation label visible and never describe authorization as settlement.
